# Quranic Arabic Corpus morphology

The controlled morphology refresh uses Quranic Arabic Corpus 0.4-derived
annotations for roots, lemmas, part of speech, features and segmentation.

Source: https://corpus.quran.com/
Refresh source: `QAC_MORPHOLOGY_URL` (the local bootstrap defaults to the
public QAC-derived morphology repository used by the importer).

The source remains provider evidence. Project-authored teaching overrides,
including the learner-facing `أَ + عُوذُ` split, are kept distinct from the
provider record. Preserve the source attribution and the provider licence
terms before redistributing a downloaded raw artifact.
