## Research decisions

1. Quran.Foundation is the primary API integration but requires backend credentials. Public access to the learning app does not mean credentials are exposed to the browser.
2. Tanzil is retained verbatim as a separate source because its text terms prohibit changing the text and require attribution.
3. Quranic Arabic Corpus and QuranMorph are imported as separate morphology evidence. Their differences must be reviewable.
4. The project’s root pictures, contextual meanings, sentence maps and form-family teaching are authored content and must not be passed off as provider output.
5. Ordinary explanatory Arabic can use Noto Arabic; the actual Qur’anic text must use the dedicated Qur’anic font approach selected during Prompt 2 font QA.
6. Paged.js is the first print implementation because the content already has an HTML/CSS renderer shape; Vivliostyle is the contingency path if book pagination or EPUB requirements expose gaps.

## Licensing gate

Before public launch, Prompt 2 must record the exact approved translation(s), translator permissions or terms, provider attribution text, Tanzil notice and font licenses in a `NOTICE`/credits page and generated PDF credits. No translation is treated as freely redistributable merely because an API returns it.
